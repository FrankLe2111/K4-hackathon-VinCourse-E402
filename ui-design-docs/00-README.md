# VinCourse UI Design Documentation

Bo tai lieu nay mo ta giao dien san pham VinCourse cho hackathon 1.5 ngay, dua tren `VinCourse.md` va phong cach trong `www.hellochinese.cc-DESIGN.md`.

Muc tieu khong phai xay mot LMS hoan chinh. Muc tieu la cho ban giam khao thay duoc flow cot loi:

`Admin upload PDF bai giang -> AI sinh course world -> hoc vien choi quest -> tra loi sai -> he thong phat hien misconception -> bien loi sai thanh recovery mission -> cap nhat mastery bang evidence.`

## Danh sach file

1. `01-product-scope-and-navigation.md`
   - Scope demo.
   - Hai role chinh.
   - Information architecture.
   - Luong dieu huong tong the.

2. `02-visual-style-guide.md`
   - Cach ap dung design system HelloChinese cho VinCourse.
   - Mau sac, typography, spacing, component tone.
   - Do and don't rieng cho UI hoc tap dang game.

3. `03-admin-ui-screens.md`
   - Tat ca man hinh role admin/instructor.
   - Upload PDF, generation progress, course world review, question review, publish, analytics.

4. `04-student-core-screens.md`
   - Tat ca man hinh hoc vien cot loi.
   - Course map, quest intro, question play, wrong feedback, recovery, result, dashboard.

5. `05-game-modes-ui.md`
   - 7 mode choi day du:
     - Story Quest
     - Daily Recall
     - Error Dungeon
     - Lab Arena
     - Boss Battle
     - Live Class Battle
     - AI Adversary

6. `06-components-and-states.md`
   - Component library can thiet.
   - State, interaction, responsive behavior.

7. `07-hackathon-build-plan.md`
   - Ke hoach build giao dien trong 1.5 ngay.
   - Uu tien demo.
   - Data mau nen chuan bi.

## Nguyen tac thiet ke lon

- Game mechanics phai phuc vu viec hoc, khong chi lam dep.
- Sai khong bi phat nang; sai mo ra nhiem vu sua loi.
- Moi cau hoi/giai thich can co dau vet nguon tu tai lieu.
- Mastery khong chi la diem so; mastery can co evidence.
- UI phai vui, sang, de tiep can, nhung van du tin cay cho giang vien.
